# ⚡ FinZip

**FinZip — suas finanças, num zip.**

Aplicativo financeiro voltado para jovens que querem organizar seus gastos, criar metas de economia e começar a construir hábitos financeiros saudáveis de forma simples e visual — sem planilha, sem complicação.

> Projeto acadêmico desenvolvido para a disciplina de Engenharia de Software — FIAP, Engenharia de Computação (3º ano).
> Checkpoint atual: **CP4 — Idealização**.

---

## 📌 Sobre o projeto

Jovens costumam ter dificuldade em controlar o próprio dinheiro: mesadas, primeiros salários e freelas somem sem que fique claro onde foram parar. Apps financeiros tradicionais (bancos, planilhas complexas) são pensados para um público mais velho, com uma linguagem e uma quantidade de informação que afastam quem está começando agora.

O **FinZip** propõe uma forma simples e rápida de acompanhar gastos, definir metas pequenas e alcançáveis e visualizar o dinheiro evoluindo ao longo do tempo — com uma interface leve, direta e sem jargão financeiro.

A descrição completa do problema, persona, requisitos funcionais/não funcionais e escopo está sendo documentada em [`docs/`](./docs) como parte da entrega do CP4.
